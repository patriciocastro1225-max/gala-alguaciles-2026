# Instalación 3.0.2

1. Ejecutar `VERSION3_0_2_EJECUTAR.sql` en Supabase.
2. Reemplazar el contenido del repositorio por esta versión completa.
3. Confirmar las variables de Netlify:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. Hacer commit y push a GitHub.
5. Esperar el despliegue automático de Netlify.
6. Probar `/inscripcion` y `/admin/validaciones`.
7. Verificar `/sprint-version.txt`.
