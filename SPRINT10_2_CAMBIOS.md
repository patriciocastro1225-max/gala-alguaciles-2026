# Sprint 10.2 — Base de datos instalable

Cambios principales:

- Archivo único `database.sql` para instalar Supabase.
- Creación automática de tablas, relaciones, vistas, índices y políticas RLS.
- Creación y actualización idempotente de 23 mesas protocolarias.
- Perfil automático para usuarios de Supabase Auth.
- Primer usuario existente configurado como administrador.
- Configuración general del evento almacenada en `event_config`.
- Vista `dashboard_metrics` para el panel ejecutivo.
- Vista `table_occupancy` para el plano de mesas.
- Manuales de instalación para Supabase y Netlify.
- Mensaje de error de base de datos más comprensible en el Dashboard.
