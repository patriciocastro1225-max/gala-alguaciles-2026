# Versión 1.0 — Plataforma Gala Alguaciles 2026

Esta versión consolida los módulos desarrollados para la II Gran Gala Nacional
de los Alguaciles de Chile 2026.

## Sitio público

- Cuenta regresiva al 25 de noviembre de 2026 a las 20:00 horas.
- Programa de la noche.
- Información de vestimenta, puntualidad y ubicación.
- Círculos participantes conectados a Supabase.
- Mensaje institucional único para invitados de renombre nacional e institucional.
- Fotografía final del Club Palestino optimizada para web.
- Diseño responsive para computador, tablet y teléfono.

## Administración

- Autenticación con Supabase.
- Recuperación y cambio de contraseña.
- Dashboard con indicadores reales.
- Administración de asistentes.
- Administración de Círculos.
- Control de pagos.
- 23 mesas protocolarias.
- Asignación de asistentes a mesas.
- Check-in y control de duplicados.
- QR único por asistente.
- Etiquetas de 100 × 50 mm.
- Módulo de correos preparado para Resend.
- Historial y auditoría de operaciones.

## Infraestructura

- Supabase como base de datos y autenticación.
- Netlify para publicación y funciones.
- GitHub como repositorio.
- Políticas RLS para proteger la información privada.
- Script SQL de instalación y actualizaciones de base de datos.
