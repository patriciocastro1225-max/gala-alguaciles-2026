# Versión 1.1 — Mesas personalizables

## Cambios

- Renombrar cualquiera de las 23 mesas.
- Cambiar capacidad.
- Definir zona protocolar.
- Cambiar estado: Disponible, Reservada o Cerrada.
- Elegir color identificador.
- Registrar ubicación dentro del salón.
- Registrar responsable.
- Agregar observaciones.
- Mantener el número interno de la mesa para orden y trazabilidad.
- Mostrar el nombre personalizado en asignaciones, credenciales y consultas relacionadas.

## Instalación

1. Ejecute `VERSION1_1_EJECUTAR.sql` en Supabase.
2. Publique esta versión en Netlify.
3. Abra Administración → Mesas.
4. Seleccione una mesa y presione **Editar**.
