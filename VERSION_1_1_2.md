# Versión 1.1.2 — Edición general de mesas

## Nueva función

En Administración → Mesas aparece el botón:

**Editar las 23 mesas**

Este abre una pantalla única para cambiar:

- nombre visible;
- capacidad;
- zona;
- estado;
- color.

Después se guardan las 23 mesas con un solo botón.

## También se conserva

- edición individual;
- ubicación;
- responsable;
- observaciones;
- asignación y retiro de asistentes;
- validación de capacidad;
- colores personalizados.

Esta versión no requiere una nueva migración SQL si la Versión 1.1.1 ya fue ejecutada correctamente.
