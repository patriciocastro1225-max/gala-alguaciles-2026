# Versión 2.2 — Gestión avanzada de invitados

## Nueva gestión de invitados

Nueva pantalla **Gestión invitados** con:

- ficha completa del invitado;
- nombre, correo y teléfono;
- acompañante;
- institución y cargo;
- categoría protocolar;
- Círculo;
- mesa;
- confirmación;
- pago;
- restricciones alimentarias;
- observaciones.

## Alertas operacionales

- confirmados sin mesa;
- pagos pendientes;
- invitados sin correo;
- invitados sin QR.

## Búsqueda global

Busca por:

- nombre;
- correo;
- teléfono;
- Círculo;
- nombre de mesa.

## Reporte por mesa

Nueva opción **Listado por mesa**:

- muestra las 23 mesas;
- nombre personalizado;
- capacidad y ocupación;
- lista de invitados;
- estado de check-in;
- impresión directa.

## Base de datos

No requiere una nueva migración SQL si las migraciones anteriores ya se ejecutaron,
porque utiliza campos existentes desde la instalación base.
